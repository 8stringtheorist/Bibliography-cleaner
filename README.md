# Bibliography-cleaner
A useful small script to clean a LaTeX bibliography file (.bib) and convert the journal names from long to shorter version. It was created to help me into converting my dissertation's ABNT-ready bibliography entries to internationally accepted formats (e.g., PRD-style).

Instructions:
1 - Put both the bib_clean_and_map.py and run.bat files and the bib file you want to clean in the same folder,
2 - Edit the run.bat to correctly read the bib file you want to clean and to properly call python in your system,
3 - Run the bat file.
